# Historical V1 development scripts

These scripts are preserved for provenance but are not entry points for the
current optimizer comparison. They produced stopped or superseded development
diagnostics. The frozen V1 paper evidence and its exact source remain available
at Git tag `paper-v1-d5e3c28`; current development uses
`scripts/run_portfolio_campaign.py`.

Only one-off scripts with no active code, test, documentation, or paper
reproduction references were moved here. Evidence helpers still imported by
tests, and the historical campaign module those tests import, remain in
`scripts/`.
